## 2. 过程中发现并修复的一个既有缺陷

`lib/patchfile.js` 的 `yamlScalar` 用 `/^[A-Za-z0-9_.\-/:@]+$/` 判定"可以裸写"，但 YAML 的 plain scalar **不能以保留指示符开头**——包括 `@`。于是任何带 scope 的 npm 包都会被渲染成：

```yaml
    - @modelcontextprotocol/server-everything
```

loader 报 `bad indentation of a sequence entry`。因为该值总是落在 `args` 列表里，校验门拦住了它、活文件没有被破坏；但**`dsh-mcp add` 加不了任何带 scope 的包**——也就是绝大多数 MCP 服务器——CLI 与工具两条路都不行。

修复后开头规则显式化（`-`、`?`、`:` 仅在后跟非空格时可用，因此 `-y` 保持裸写），另外把会被 YAML 读成其它类型的值（`true/false/yes/no/on/off/null/~`、数字）也加了引号。

回归测试：`test/patchfile.test.mjs` 新增两条，其中一条把带 scope 包的整行渲染出来**真的过一遍校验门**。
