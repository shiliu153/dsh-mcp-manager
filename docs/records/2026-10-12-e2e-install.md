## 过程中发现并修复的实现缺陷(均有回归测试)

1. `appendEntry` 对 configLines 重复缩进 → 产出非法 YAML(校验门抓到)。
2. `setDisabled` 插入行时行块边界错位,破坏后续行(校验门抓到)。
3. probe 裸命令解析:Windows 上 `npx` 命中 bash 包装脚本 / Node 22 拒绝直接 spawn `.cmd`(`EINVAL`)→ 按 cross-spawn 语义先试 PATHEXT 扩展、`.cmd/.bat` 经 `cmd.exe /c "<path>"` 包装,与官方 MCP SDK 行为对齐。
